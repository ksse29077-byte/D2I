# AI Safety Operations Employee

This is the canonical WORK-100 safety-operations Role example for later
WORK-200 through WORK-800 work. It declares five work-class references, KPI and
SLA targets, memory limits, and Human-by-Exception routing classes.

It runs no Case, measures no KPI, starts no SLA timer, routes no recipient, and
grants no write capability in WORK-100.

The `cases/` directory adds execution-free WORK-200 references for training
compliance follow-up and corrective-action tracking. They contain only opaque
subjects, typed requirements, evidence classes, and terminal outcome rules.
