# Kernel E2E Operator

This Role source is the WORK-100 executable vertical. It admits only
`workforce.kernel_e2e.name_save`, narrows authority to the exact KRN-500
Application Pack, and permits `uia.set_value` autonomously while requiring the
existing policy path for `uia.invoke` business-state mutation.

The source is not an execution permit and contains no locator, credential,
process ID, window handle, Work Item, or Case.
