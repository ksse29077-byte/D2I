# Presentation Design v1

Presentation design features are derived from the existing bounded OFFICE-400
semantic snapshot. Shape bounds are already normalized millionths. Slide
purpose, layout, semantic slots, table/chart/image presence, density, alignment,
and source hashes become design facts; slide text and raw PresentationML do not.

The layout solver selects an approved organization/artifact-class family and
assigns only compiled slots. Typography selects preferred or explicitly
approved installed fallback fonts and remains inside pack size and spacing
ranges. Chart values continue to come from OFFICE-300 typed facts; the Design
Pack controls visual roles only.

Certified quality uses installed signed PowerPoint through the existing
private-desktop worker. Macro security is forced off, PowerPoint and chart
Excel are exact-image and temporary-WFP bound, results are saved to a new
generation, freshly reopened, rendered to PNG, and checked for overflow and
residual processes. Interactive user Office processes are baseline-preserved.

An initial content-fit failure must produce a closed bounded refinement and a
subsequent hard/soft pass. A language model can shorten claim-preserving prose
inside a stated character range; it cannot control layout or geometry.
